# Project 01 - Linux Server Administration

## Objective

The objective of this project is to build and administer an Ubuntu Server virtual machine using KVM/QEMU and libvirt.

This project focuses on the core Linux and server administration skills required for Fachinformatiker für Systemintegration.

## Planned Environment

- Host OS: Ubuntu Linux
- Hypervisor: KVM/QEMU
- Virtualization management: libvirt
- Guest OS: Ubuntu Server
- Server hostname: srv-linux01

## Learning Goals

During this project I will learn how to:

- Install an Ubuntu Server virtual machine
- Configure networking
- Configure a static IP address
- Install and configure SSH
- Create and manage users and groups
- Manage permissions
- Configure sudo access
- Manage services with systemd
- Configure a firewall
- Inspect system logs
- Diagnose network problems
- Troubleshoot server problems

## Project Stages

1. Ubuntu Server installation
2. Initial system checks
3. Network configuration
4. Static IP configuration
5. SSH configuration
6. User and group management
7. Permissions and sudo
8. systemd service management
9. Firewall configuration
10. Logging
11. Troubleshooting exercises
